Dato che con docker compose down -v venira perso anche il modello, che era all'interno di un vaolume,
adesso il modello è in un volume esterno, che si crea cosi:

$ docker volume create sentiment-ov  


Il modello è all'interno dell'immagine docker, dobbiamo esportarlo e salvarlo nel volume

$ docker compose run --rm --no-deps --entrypoint python3 spark-driver-q1 \
  /opt/spark/jobs/ov_export.py --variants fp32


Per verificare se q1 sta lavorando usiamo questo comando:

$ docker logs -f spark_q1 2>&1 | grep -E "\[q1\]|\[progress\]"
